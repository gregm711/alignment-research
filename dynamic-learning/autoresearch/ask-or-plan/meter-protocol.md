# Local power measurement

Exploratory addition before opening either test set. The installed macmon utility exposed CPU and system power estimates without elevated privileges. Measure only the local execution cost of choosing a line and returning its index. A simulated live check reads a pre-generated bit in memory. External observation, communication, model development and training costs are outside this measurement.

Generate 256 standard calibration maps from seed range 510000 once. For the meter only, draw a delay bit at the published probability on each map and reuse it for all arms. Run single-threaded scalar Python, computing cheap features on each decision, and compute the exact routes only if the selected action calls for them. Replay each fixed baseline and the frozen adaptive tree alongside an idle arm. Repeat four blocks with shuffled arm order (seed 53), 2.5 seconds per arm. Read macmon at 200 ms, exclude the first 0.65 and last 0.25 seconds of each arm, and retain raw samples. Record completed decisions, process CPU seconds, elapsed time, average estimated CPU and system power, and block-matched idle-subtracted energy per decision. These are shared-machine, sensor-derived estimates. Summarize the median and range across blocks, retain negative estimates, and make no energy ordering claim for contrasts whose signs vary. Predict only that exact planning requires more CPU time per decision than stopping. Validate the scalar deployment against the vectorized selectors before timing.
