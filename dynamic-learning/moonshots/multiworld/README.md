# Four live hypotheses after a correction

## Registration before outcomes

Can explicitly retaining competing configurations help a diagnostic system revise after a late trusted reading? Test the state representation and query rule separately. This local pilot covers a finite, known model; no neural modules are trained.

A synthetic device has five unknown binary switches, uniformly distributed across 32 wirings. Its 31 available sensors each return the parity of a distinct nonempty subset. Six noisy readings of randomly selected sensors, sampled with replacement at 87.5% reliability, precede a restart. A late calibration on one of these six sensors reveals its true value. Enumerate both calibration futures and weight them by their exact posterior probabilities. Score the subset that contradicts the old reading separately. After calibration the operator must decide a new binary service setting, the parity of a different random subset. It may first request one of five random, distinct trusted sensors; these exclude the target and calibration sensor. All methods receive the same transcript, target and menu, and one verified probe. The common device model, calibration identity and target are public.

Limit persistent evidence at restart to four bytes. Compare four weighted branches (world id plus three-bit relative weight each), six deterministic stratified particles (five bits each), five separately quantized switch marginals (six bits each), five most recent raw reports (six bits each), and a lossless combinatorial code for the unordered multiset of six reports. The last is a deliberately strong conventional comparator. Likelihood products commute in this model. The unordered code fits when the number of possible multisets is at most 2^32. Reconstruct approximate posteriors from serialized bytes and give each lossy distribution 1% shared uniform support to recover after an incompatible calibration. Decode the lossless code exactly. Also include one MAP branch and a calibration-only uniform reader as controls.

Use the same enumerative Bayesian prediction interface for all readers, with fixed tie breaks. On each future compare the query maximizing expected service-decision accuracy with the query maximizing binary sensor disagreement. For a matched-evidence comparison, all readers also replay the query selected by the exact state's decision-value policy. Include calibration alone as a zero-probe reference. Marginalize both possible values of every chosen probe exactly. Pair cases by seed and quantify uncertainty across 1,024 independent transcripts, seeds 947000–948023 inclusive, using 4,000 paired bootstrap draws with seed 947. Record per-case expected accuracy, the mass and correct mass under contradictions, and serialized state. Evidence gives scores, not the hidden world, to each policy. Report time and memory accounting separately; no energy claim.

Predict the four weighted branches gain at least 3 percentage points over five marginal probabilities on common evidence (mean hurdle and paired 95% lower bound above zero), and their decision-value query gains at least one point over pure disagreement on their own state under the same rule. Advance a branch-specific architectural claim only if it also beats the strongest byte-matched conventional comparator by at least one point with lower bound above zero. The exact code is an analytic upper bound under the stated generative model; matching it with materially less measured work could motivate a different study. Contradiction-only accuracy is secondary. Reproduce the compressed outputs twice; compare the exact reader against the unsaved full posterior and assert that no lossy decision can exceed the exact decision value on any transcript.

## Pilot outcome

Four branches retained associations between switches that five separately stored probabilities lost. Under identical oracle-selected queries, the gain was **10.09 percentage points** (paired 95% interval 8.99–11.18). Selecting a question for its expected effect on the service action gained **5.45 points** over choosing the sensor with the highest disagreement (4.88–6.06). Both registered comparisons passed.

| Restart state | Decision-value query | Maximum disagreement | Same oracle query | Calibration alone |
|---|---:|---:|---:|---:|
| Four weighted branches | 88.04% | 82.59% | 89.04% | 73.23% |
| Six stratified particles | 87.09% | 81.47% | 88.30% | 72.45% |
| Five marginals | 80.38% | 73.20% | 78.96% | 67.81% |
| Latest five reports | 89.00% | 82.31% | 88.50% | 69.87% |
| Exact multiset of six | **91.07%** | 84.69% | 91.07% | 73.97% |
| Most likely branch | 75.32% | 71.48% | 79.01% | 70.10% |
| Uniform prior | 57.57% | 51.04% | 57.57% | 49.27% |

The branch-specific advancement gate failed. Six unordered reports drawn from 62 types have 99,795,696 possible multisets. A 27-bit combinatorial rank preserves every likelihood factor. Reading this code beat four branches by 3.02 points (2.76–3.32). When calibration contradicted an old reading (12.34% of posterior mass), the respective accuracies were 91.18% and 77.92%. Even keeping the latest five plain reports achieved 89.00% on those contradictions. Once a plausible low-prior wiring is discarded, a posterior update can restore it only through the small uniform fallback.

The exact reader's two query rules picked different sensors in 64.6% of future mass and differed by 6.38 accuracy points (5.82–6.96). A sensor can split the candidate wirings evenly while revealing little about the maintenance action. The replay column lends all systems the same query identity, which itself may carry information about the full transcript. Decoders used only its observed bit and the stated sensor identity for Bayesian conditioning.

The pilot used 32 known configurations, supplied the likelihood and service rule, and serialized four bytes for every arm. Inference expanded all representations to the same 32-entry workspace. Enumerating that workspace for comparison provides no evidence about training, physical energy, or speed at scale. A total pilot sweep took 0.75–0.78 process CPU seconds here. Two independent executions reproduced the raw observations and summary byte-for-byte. Run `OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 python3 study.py` from this directory. ## Learned branches follow-up registered before fitting

Train a differentiable four-slot writer on independent simulated six-report transcripts with true wiring supervision. Each slot emits a 32-way softmax over worlds; a shared gate emits four mixture probabilities. Minimize the negative log probability of the true wiring in the mixture. Compare ordinary training to the same objective with a 0.1 dot-product-overlap penalty averaged over the six pairs of slots. At restart select the mode of each slot and quantize the four mixture weights to three bits relative to the largest, using the previously frozen four-byte branch decoder. No test labels or pilot cases enter training. Use three fixed initializations per arm, a 64-unit tanh hidden layer, Adam at 0.004, 800 batches of 128, CPU only. Score 512 new transcripts (seeds 952000–952511), one decision-value probe using the original evaluation procedure. Report accuracy, number of distinct modal worlds and comparison against exact analytical four-branch compression on the same cases. Predict that the overlap penalty improves mean accuracy by at least two points and brings learned branches within five points of the analytical writer. Compare paired cases averaged over the three trained instances; this interval conditions on these instances. No tuning if the threshold fails.

## Matched learned bottleneck registered before its training

Add a general 32-bit single-state bottleneck. A linear/tanh hidden layer and a 32-bit straight-through binary write feed a learned linear 32-world decoder. Use 121 hidden units, giving 12,583 trainable parameters, versus 12,612 for four categorical slots. Verify counts and report multiply-adds. Train with the same true-world negative log likelihood, seeds, example stream and 800 optimizer updates per initialization. Compare against the previously specified plain and overlap-regularized four-slot writers; use fresh seeds 953000–953511. Serialize both through four-byte buffers before recovery. Report the analytical exact-state and analytical branch references on the same cases. Add the same 1% recovery prior to both learned representations. Score decision-value and common oracle-selected probes. Predict that four overlap-regularized slots gain at least two points on common evidence over the ordinary learned state (lower paired 95% bound above zero). A positive claim must also survive actual CPU accounting. Measure training CPU seconds and full single-case write, serialize, restore and one-fork query-selection CPU time on a separate 128-case calibration set. Time three shuffled sweeps per implementation, under single-threaded Torch/NumPy. Report actual work separately from nominal parameter/MAC counts; no joules or frontier inference claims.

## Learned writer outcomes

The mixture writer learns from the true wiring label of each synthetic training case. Gradient descent changes four categorical predictions and their gate; only their four modal wirings and relative weights survive the restart. Training scores the full soft mixture, so the hard restart itself introduces a train–deployment mismatch. The general learned writer instead passes hard bits in its forward pass and differentiates through sigmoid probabilities during the update. Both receive 102,400 labeled practice cases per initialization.

The overlap penalty increased mean distinct serialized wirings from 2.11 to 2.69 of four. Its gain in post-calibration service accuracy was 0.33 percentage points (paired interval −0.07 to 0.74). The analytical four-branch rule led it by 5.90 points (5.19–6.64). Both predictions for the learned penalty failed. Three seeds measure variation for these implementations; intervals condition on them. On identical evidence, diversity-regularized slots gained 0.80 points over the ordinary learned state (−0.21 to 1.80), ruling out the registered two-point advantage under this training procedure and test stream. With each policy choosing its own question the gap was −0.37 points (−1.46 to 0.76). A fairer hard-quantized training objective for the slots remains a plausible alternative. The exact code beat learned slots by 9.34 points (8.56–10.13) with each policy choosing its own question.

The slot and ordinary nets used 12,612 and 12,583 trainable parameters. Their linear layers performed 12,416 and 12,398 multiply-adds per write/read. On this machine, training a seed took 0.55–0.67 process CPU seconds for ordinary four-slot training, 0.86–0.97 for the diversity penalty and 0.43–0.48 for the binary state. A timed write, restart, calibration and question selection took 67–72 µs for the diversity writer, 60–67 µs for the binary writer and 33–34 µs for the exact code. Timings reflect this Python/NumPy/Torch implementation. Public likelihood knowledge and analytically supplied posterior decoding favor the classical control. The 32-bit limit counts per-instance state; shared trained parameters and the public sensor truth table are excluded. Use the same single-thread environment as the first pilot and run `python learned.py` then `python bottleneck.py` with compatible NumPy and PyTorch installs (tested with NumPy 1.24.4, PyTorch 2.1.0.dev20230517). For learned raw files, columns after the seven original arms are three plain-slot seeds followed by three diversity-slot seeds. The last cohort appends three binary-writer seeds. An independent integer-arithmetic oracle matched the first 32 original per-case upper bounds, and the exact archive round-tripped boundary multisets and 1,000 fresh random ones.

The mechanism worth retaining is the distinction between a question that separates live explanations and a question whose answer changes a downstream decision. The pilot gives little reason to enlarge the learned four-slot writer on this task.

A second run of each learner reproduced every saved four-byte state, every decision score and both learned raw archives byte-for-byte. Runtimes varied, maintaining the same median ordering in the independent timing run.
