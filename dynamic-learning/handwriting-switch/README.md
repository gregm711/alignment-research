# What does a history of genuine rule changes teach a weight updater?

## Protocol fixed before the first fit

The old rule sorts by a supplied binary mark. The new task sorts real handwritten images by which of two digits they depict. Mark and identity are independent on test queries. At the start both learners use the exact same old weight and produce identical logits on every input. Each lesson opens with a report contradicting the mark. In a change episode that report is true and all future labels follow digit identity. In an exception episode only that first report is false and all verified labels follow the old rule. The initial report, its image and all query inputs are identical in the two forks. Later checks arrive at the same times and use the same images and marks. Independent verified labels can distinguish the worlds. A learner is explicitly told which example is the opening report.

Eight paired lifetimes see the same practice images and openings. For one learner, changes have 80% weight in the audited practice objective; for the other, changes have 20%. Integrate both forks in each update. This isolates the relative prevalence of the two histories at fixed compute. Use 100 minibatches of 24 episodes per lifetime. Use all pairs of digits 0–5 for practice. Reserve all six contrasts among 6–9 for evaluation, with 192 episodes per contrast, randomized binary label orientation, support sampled without replacement and sixteen disjoint queries per class. Practice and test share neither images nor digit identities. Report results for each pair. Digit discrimination is a new task of a practiced kind. The old mark and the changes of task are constructed. [Handwritten image dataset](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_digits.html)

The model writes a temporary candidate pixel classifier by online logistic gradient steps, with slow learned per-pixel step sizes. A learned gate then writes a single effective weight vector combining the old mark coefficient and the candidate pixel coefficients. The gate can depend on its bias, the number of confirmed agreements and disagreements with the old rule, and the accumulated predictive evidence from the candidate before each verification. These counts exclude the disputed opening. Start both arms with identical parameters. Swap just the gate or just the pixel step sizes after training, preserving the other half. Store one written weight and verify that a fresh process reproduces its predictions with no episode history.

Score honest changes and stable episodes with a false report after 1, 2, 4 and 8 observations, counting the disputed report as the first. Use mean held-out accuracy across these budgets and report the fraction reaching 80% accuracy by each budget. Count future errors repaired relative to the original old weight on the truthful fork, and original correct answers broken on the false fork. The main comparison is change-heavy minus exception-heavy practice. Require an average accuracy gain of at least three percentage points on novel changes with a positive paired 95% lower bound, and an upper bound below two points for excess harm on the stable fork. Report the same contrasts after the first observation separately. Include a frozen old weight, always trusting the candidate, a rule that waits for a second contradiction, and an analytic posterior gate with equal and history-specific prior probabilities. For the hand baselines select one scalar pixel step size from 1, 4, 16, 64 using an independent balanced practice evaluation. The mark-only posterior odds use the fact that subsequent reports are verified and marks are independent fair coins. Posterior mixing here acts on the classifier weights.

Equal-weight the six test pairs and eight paired fits. Use paired resampling of training seeds and episodes within each fixed pair, preserving both forks, all methods, and budgets. Report uncertainty conditional on these four test identities. A publication-level advantage would also require a three-point improvement over the strongest balanced-practice-selected hand baseline in balanced-fork accuracy. The first report offers no way to tell the worlds apart. A later check creates the opportunity to gain accuracy without immediately accepting an unsupported correction.

## First result

Averaged over the four budgets, change-heavy practice improved new-task accuracy by 10.08 points (paired interval 9.70 to 10.48) and truthful repairs by 22.95 points (22.22 to 23.67). It also increased false-report harm by 13.40 points (12.97 to 13.80). After just the ambiguous opening, new-task accuracy was 70.8% versus 49.8%, while 27.3% versus 0% of previously correct answers broke in the stable world. After eight observations the respective new-task accuracies were 92.3% and 91.3%, and harm fell to 0.3% and 0%. The practical joint criterion failed.

| Intervention on the exception-heavy learner | Change in new-task accuracy | Change in false-report harm |
|---|---:|---:|
| Transplant four gate coefficients | +10.57 points | +15.44 points |
| Transplant 64 pixel step sizes | +0.03 points | 0.00 points |
| Transplant both | +10.08 points | +13.40 points |

The differences locate most of the effect in how readily the learned gate commits a candidate classifier. The architecture assigns these two parameter groups distinct roles by design. A simple control that waited for a verified contradiction beat the change-heavy learner by 2.52 points in balanced-fork accuracy and the exception-heavy learner by 0.86 points. The saved 65-weight classifier reproduced all 32 query decisions in an independent NumPy readout. Run `python3 experiment.py` and `python3 analyse.py`. Use the same held-out identities 6–9, 256 fresh episodes per pair and 32 balanced queries. No fine-tuning. Sample a disputed opening and two disjoint eight-image menus with independent marks. The first report again contradicts the mark in both worlds. At each of the two checks select an image, observe a potentially imperfect verification, and take one logistic gradient step on a provisional pixel classifier. Apply the candidate classifier to new queries only if both verification labels contradict the old rule. Until then the old classifier continues to answer. This separates the time an example is learned from the time its consequences reach decisions.

The primary selector takes the image for which the candidate most confidently opposes the old mark. Compare the first randomly ordered image and the highest-confidence image regardless of its mark. All methods receive the same menus, use exactly two verification labels and face the same withheld queries. The primary writer uses the scalar step size of the previous validation-selected wait baseline. Secondary writers use each of the eight change-heavy fitted pixel update vectors. Report a one-confirmation gate and a version that waits for both confirmations then learns only from the final image, using identical acquisition paths. At each check integrate all four possible answer-error paths exactly. Primary condition is independently wrong checks with probability 10% each. ## What the choice of check changed

On 1,536 fresh episodes, the scalar writer reached **71.79%** new-task accuracy when asked to check the two examples where its provisional prediction most strongly opposed the old rule. Random selection reached **58.28%** with the same two checks and the same release rule. The paired difference was +13.51 percentage points (95% interval +12.67 to +14.40). Selecting high-confidence examples without considering disagreement reached 56.28%. The old rule was replaced in 69.58% of genuine changes with disagreement selection, versus 24.81% with random checks. In stable episodes both released the candidate exactly 1% of the time under independent 10% verifier errors; the disagreement selector broke 0.50% of previously correct answers (0.49% to 0.50%). The specified joint comparison passed on this constructed switch.

| With disagreement selection and independent errors | New-task accuracy | Stable answers broken |
|---|---:|---:|
| Accept one of two checks as confirmation | 75.37% | 9.48% |
| Require both checks to confirm | 71.79% | 0.50% |
| Require both, then learn using only the last image | 70.40% | 0.50% |
| Require both, using the learned pixel step sizes | 71.88% | 0.50% |

Retaining the provisional classifier's writes improved accuracy by 1.39 points (+1.00 to +1.79) over rebuilding from the final image on the identical acquisition path. The learned pixel step sizes added 0.08 points relative to the scalar writer (−0.32 to +0.49). The main gain came from which evidence was sought and when a candidate weight was allowed to control the answer. The learned-architecture criterion failed.

The independence assumption matters quantitatively. When both checks inherited the same error, each check was still 90% accurate, but 10% of unchanged worlds received two false confirmations. The two-confirmation method then broke **4.98%** of previously correct answers. The 1% and 10% false-release rates follow directly from the specified error models. The measured quantities are the usefulness of selected evidence in the changed world and how many wrong predictions follow each release. This study does not test a language model, adversarially targeted verifier errors, or a learner that must discover the possible rules on its own. The candidate is explicitly a pixel classifier, and the old classifier reads the artificial mark. Each check can inspect eight candidate images and buys one label.
