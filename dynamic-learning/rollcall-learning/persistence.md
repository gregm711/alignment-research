# When does a contradiction predict a lasting change?

## Protocol recorded before building the episodes

A historical House member usually voted a particular way when three other members voted a particular way. Now there is a report that contradicts the old pattern. Given one verified observation, which is more informative about the next four comparable decisions, checking the reported ballot itself or observing the next occasion on which the same three witnesses voted the same way? Both methods forecast at the same time, after the second occasion. This is a feasibility test for a learner deciding whether to rewrite an old association. The recorded outcomes can establish predictive persistence over four more occurrences. They cannot identify a member's motives or a permanent change.

Use the existing previous-Congress-only 64-person panel selection with seed 7000 plus the new Congress. For each target, use the next three panel members cyclically as the fixed witnesses. For each of their eight binary patterns, compute the target's majority ballot in the previous Congress using only complete cases. Require at least 20 observations and at least 80% agreement. Define the smoothed probability of deviating from the old majority as (exceptions + 1)/(observations + 2). Handle all later labels as either agreement with the old habit or deviation from it.

Divide the new Congress chronologically into nonoverlapping blocks of 64 eligible motions, including the final partial block. Within a target, pattern and block, take consecutive nonoverlapping groups of six complete cases. The first is the imperfect report, the second is the independent check, and the last four are held-out targets. Never carry evidence across these groups. Both verification arms have the same elapsed time, opportunity set and forecast positions. Eligibility uses availability of future observations; this estimates performance on historically recurring patterns and is retrospective. Truthful and false reports have known probabilities 0.9 and 0.1. Integrate both possibilities exactly. The primary population consists of reports of a deviation from the old habit. Each episode is weighted by the probability of getting that report given its actual first ballot. Score each future ballot by squared probability error and average the four. Give the two evaluation Congresses equal weight. Separately report the fraction of episodes with at least three future deviations and the frequency of falsely reported contradictions.

Learn the response to observations on the six chronological transitions ending in Congresses 111–116. Freeze all settings before evaluating 117–118. The slow weights store empirical probabilities of future deviation, stratified by historical exception probability (<5%, 5–15%, or higher), check type, report value and check value. Shrink each cell toward its historical exception rate with 32 pseudo-episodes. The fast weight in a target and witness-pattern slot is a single log-odds parameter reset to the old habit, then written from the selected cell. A fresh query reads its sigmoid. Compare against the unchanged old probability and an old-probability Beta prior updated with the verified observation; in the independent arm also add the expected first ballot conditional on the report under the old prior and known flip rate. Select prior strength from 1, 2, 4, 8, 16, 32, 64 on the six training transitions for each check type. Include report-only and check-only empirical models. The latter tests whether keeping the disputed report adds anything after the independent check.

Primary contrast is the difference in future-ballot Brier loss between the independently checked weight and the directly rechecked weight on contradictory reports. Require at least 0.005 lower loss for the independent check and a paired 95% upper bound below zero. A separate test of whether learning the weight-write rule earns its cost requires at least 0.005 lower loss than its tuned Beta control with an upper bound below zero. For the incremental contribution of the report, measure truthful repairs among future ballots the check-only learner missed, and harm from false reports among those it got right, including counts. Report accuracy, forecast probabilities and Brier separately on true versus fabricated contradictions. Bootstrap entire 64-motion blocks within each period, keeping all targets, witnesses and overlapping motions together, using 4,096 paired draws. The same people can appear in multiple blocks; this uncertainty is conditional on these panels and histories. Show contrasts by Congress. Only one independent check is allowed; any advantage establishes predictive value at this delay and check budget.

Choose each Beta strength on the primary contradictory-report population, weighting training Congresses equally. The empirical table uses all episodes and both report values to learn its different cells. For check-only prediction, omit the report from the table key during training as well as evaluation.

## What happened

Training covered 27,004 eligible six-event episodes across six transitions. The two evaluation periods supplied 3,659 and 4,321 episodes. Among reports contradicting an old habit, 67.0% were false under the assumed 10% source error rate. Even when the first ballot truly contradicted the habit, the deviation recurred on at least three of the next four scored occasions only 12.1% of the time (equal weight per Congress). That figure was 1.19% after a false contradiction. These are rates conditional on observing a contradiction, not the overall error rate of the simulated source. Fixed panels, future availability and the historical 80% stability filter determine this population.

| Forecast after a reported contradiction | Future-ballot Brier loss |
|---|---:|
| Keep the old weight | 0.09137 |
| Learn from the report alone | 0.08902 |
| Check the original ballot and use the learned update | 0.08430 |
| Check the next comparable ballot and use the learned update | 0.08272 |
| Check the next ballot and discard the report | 0.08459 |
| Check the next ballot and use the tuned Beta update | 0.08418 |

Independent verification gained 0.00158 Brier over rechecking the original (paired difference −0.00158, interval −0.00332 to −0.00002). It performed slightly worse in the 117th Congress (+0.00055 loss) and better in the 118th (−0.00371). The fitted update beat the tuned Beta update by 0.00146 (interval −0.00269 to −0.00029). Both effects fell below the specified 0.005. The Beta controls selected strength eight for both kinds of check.

**Every forecast still picked the old habit.** The models all scored 89.73% accuracy, with zero repairs among 421 eligible future errors after truthful contradictions and zero harms among 28,950 eligible correct future predictions after false contradictions when retaining the report alongside the independent check. The empirical model's largest probability of deviation was 30.4% after that check. Its lower loss establishes a change in confidence. This experiment gives no evidence that the learner recognized when to reverse its habitual prediction.

Post hoc, when the independently checked ballot also broke the old pattern, the weighted proportion of subsequent ballots breaking it was 22.5% in Congress 117 and 42.9% in Congress 118. This helps explain why an average weight update stayed conservative. One check on these naturally occurring events is a poor test of rapid behavioral reversal. The roll calls overlap earlier studies using different tasks; evaluation episodes were excluded from fitting the table. Shared people and adjacent Congresses limit generalization. The fast weight here is a scalar lookup-table logit, a feasibility control for later architecture work.
