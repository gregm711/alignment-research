# Phone formatting release stream

Each of 30 region streams executes the published Python port of Google's libphonenumber. The snapshots use the first available non-yanked pure-Python wheel uploaded to PyPI in each calendar year 2016–2026, from 7.5.2 through 9.0.22. The collector pins each wheel by SHA-256 and loads it in a separate isolated Python process. Locale metadata and formatting logic travel with the corresponding wheel. [Python release history](https://pypi.org/project/phonenumbers/#history) · [Upstream Python port](https://github.com/daviddrysdale/python-phonenumbers) · [Original library](https://github.com/google/libphonenumber)

The region panel was fixed before inspecting formatter outputs. It covers AR, AT, AU, BR, CA, CH, CN, DE, EG, ES, FI, FR, GB, GR, ID, IL, IN, IT, JP, KR, MX, NG, NL, NZ, PL, RU, SE, TR, US and ZA. For each region the oldest wheel supplies its calling code and up to eight distinct examples across line types. Those digits seed 40 distinct probes. Deterministic variants preserve up to four leading digits and vary the suffix and length. Each release receives identical digit strings. The collector constructs phone-number objects directly, preserves significant leading zeros, then requests NATIONAL format. Input IDs include the region so the same national digits under two calling codes remain distinct. Evaluators should expose only the declared input fields, not the ID, as evidence about formatting.

These are real software outputs on public fixtures and designed inputs. They carry no evidence of how frequently subscribers use these exact patterns. Some variants have invalid lengths or prefixes. Annual sampling omits intermediate changes and reversions. Regions may share a calling code, metadata and upstream fixes, so treating region–release pairs as independent replications would exaggerate precision.

Run `python3 dynamic-learning/skill-witness/phones.py ~/.cache/alignment-research/skill-witness/phones.json`. This uses the Python standard library and downloads the 11 pinned wheels on its first invocation. The collector checks shape, coverage and significant-digit round trips. No change frequencies or outcome comparisons were used to choose probes.
