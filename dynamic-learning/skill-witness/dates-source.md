# Historical locale formatting

The collector takes the last stable Moment release published in each UTC calendar year from 2013 through 2022 inclusive. There were nine such releases; the registry lists none in 2021. Release choices use only publication timestamps. The version, tarball URL and npm SHA-512 integrity digest are pinned. The JavaScript interpreter loads the unminified browser bundle containing locales from each verified archive in an isolated VM context. A failed exact locale selection yields a missing cell instead of silently using a fallback. [npm release metadata](https://registry.npmjs.org/moment) · [Moment localized date formats](https://momentjs.com/docs/#/displaying/format/)

A fixed convenience panel covers 30 locale IDs. English, French, German and Chinese include regional variants. The remaining choices span several writing systems and regions. These were specified before change counts or scores. Each locale receives the same valid Gregorian dates in UTC. Years 1999, 2000, 2011 and 2024, months 1, 2, 4, 11 and 12, and days 1, 4, 10, 13, the month number and the month's last day cover ambiguous day/month orders, unambiguous high days, padding, month ends, year boundaries and leap years. Duplicate ISO dates are removed. Each expected string is the actual historical bundle's result for `format('L')`, retaining all Unicode digits, literals and directional characters.

These are maintained formatter revisions on deliberately chosen inputs. The source does not measure how often particular locales, dates or versions occur in production. Annual sampling can miss intervening changes; multiple locale files in one release can also share an upstream change. The release and locale hierarchy matters when interpreting uncertainty. A formatter exposing its version or format string admits an inexpensive direct baseline. Discovering a surrogate becomes a useful comparison when only the formatter's observable behavior is available.

Run `python3 dates.py ~/.cache/alignment-research/skill-witness/dates.json` from this folder. The script uses Node and the Python standard library; package archives stay in the local cache. The JSON includes all source URLs, integrity values, Node version and null cells for missing locales. Output strings, dates and release identities are public. Checked-in code contains no generated gold labels.

The resulting panel has 112 dates and 259 available locale/release combinations (29,008 outputs). Exact locale counts by release are 24, 28, 28, 29, 30, 30, 30, 30 and 30. Two local runs with Node v22.22.0 produced byte-identical JSON, SHA-256 `06dfc26fa92b4285f72d686d3cd29f21b294124e7d8a6621442789a0c8cc91d5`. Coverage and byte equality were checked without examining changes in the outputs.
