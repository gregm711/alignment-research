# How many observations identify a rule that works on unseen compositions?

## Protocol before scoring

Use the public MiniSCAN instruction-learning task as a development check on fluid rule induction. During protocol design we saw its fourteen support examples and the paper's description of unary and binary rewrite rules. Keep the official queries and answers out of rule induction. Rename primitive inputs, operators and output symbols independently to opaque tokens. A correct answer must be an exact output sequence. Compare nearest-input copying by token edit distance, the hindsight ceiling for copying any whole observed output, a grammar synthesizer and a no-feedback version of the same synthesizer. Report per-query exact predictions, elapsed CPU time and candidate counts. CPU time is a machine-dependent measurement and does not establish energy use or scaling. This single public grammar cannot establish novelty or broad intelligence. [Lake and Baroni](https://doi.org/10.1038/s41586-023-06668-3) · [Pinned public task](https://github.com/brendenlake/MLC/blob/34837ccb06c855bb29558ad99bb1cef70debd559/data_human/few_shot/val_gold/mini_scan.txt)

The synthesizer gets a restricted instruction language. Infer primitive meanings from singleton demonstrations. Identify operators by position in simple examples. A postfix unary repeats its argument one to four times. Each binary operator emits an ordered selection of one to four left/right operands, allowing repetition. Enumerate strict precedence orders of the three operators and both associativities for repeated binary operators. Break remaining ties in a fixed order independent of the query answers. Parse named operators recursively; juxtaposed primitives concatenate. Evaluate shortest local rules consistent with simple demonstrations plus all surviving parse conventions on composed examples. Keep exact matches, and fail the task if none exist. Charge the four primitive bindings and all operator or composition examples separately.

For a second controlled test draw 96 fresh grammars with independent symbol renamings, two noncommuting binary output templates containing both operands, one unary repetition of two or three, and an independently chosen precedence order and binary associativities. Demonstrate the four primitive meanings and one application per operator on distinct operands. These seven observations identify the lexical bindings and atomic rewrites. Score the unknown composition on outputs for 24 previously unobserved nested inputs per grammar. Offer two rounds of checks from menus of eight fresh nested inputs. Compare random checks, choosing the input with maximum disagreement among surviving executable rules, and repeating the easiest check (minimum disagreement). Give all policies identical menus and held-out queries. Add an oracle control using the true rule to validate representability. Score before checks and after one and two. Require a ten-point advantage over random with positive paired 95% grammar-bootstrap bound after one active check to establish a useful observation-efficiency advantage. Report exact per-grammar solves, the fraction of surviving programs and the whole-output copying ceiling. The generator shares the specified grammar family with synthesis; this tests composition and active rule identification in that family, while invention outside it remains open.
