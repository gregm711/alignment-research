# What does shared search buy on one harder induction problem?

## Iteration one, registered before evaluation

A machine applies a hidden length-d sequence of four named operations to a symbol, drawn from an alphabet of 67. A learner receives the primitive tables, program length and four distinct input/output demonstrations. It must produce exact outputs for 12 fresh input symbols. One instruction is then replaced without revealing its position; four new demonstrations contradict the old program and 12 distinct unseen inputs are graded again. An episode succeeds only if all 24 outputs are correct. The target is behavioral equivalence on new inputs. The family prior, length and primitive semantics are supplied; the hidden sequence is newly sampled every episode.

Test the architectural idea of sharing intermediate hypotheses in a bounded workspace. Compare independent random complete programs, deterministic depth-first search sharing a prefix on one demonstration and checking survivors on the others, and bidirectional program synthesis joining partial executions on two demonstrations then validating all remaining examples. All three may first try a one-instruction repair of their last successful program. Count unsuccessful branches and their table reads, build inverse tables online at charged cost, reserve the same budget for transfer predictions, and record actual process CPU joules and elapsed time. There are no external inference calls. Communication is in-process. Limit the intermediate join table to 256 prefix programs (four levels); report entries, with no equal-byte claim. Extra compute is spent on each fixed instance, never by giving easier test cases to a smaller budget.

Use depths 2, 4, 6, 8, per-phase table-read allowances 128, 512, 2048, 8192, and 24 paired worlds per depth. Freeze seed 120310 for random invertible lookup tables and 120819 for a second family of invertible affine transformations modulo 67. Include the ordinary direct algebraic solver on the latter; charge calibration and output arithmetic, measure joules for its actual code path. Correctness on held-out symbols is verified outside the meter; generation of the provided problem and test labels is common. All learner setup, interpretation of receipts, repairs and rendering returned outputs are inside the meter. Downstream checks here mean evaluating known receipts, not querying a world for new evidence.

Predict that at depth 8 bidirectional search attains 90% exact episode solves at a lower budget than either one-ended strategy on random tables, and that direct affine induction wins on the matched-accuracy energy curve for affine data. Both are established algorithms. This experiment calibrates the price of serial vs shared computation; a new neural architecture has not been tested. Report joules per exact solve (including failures), per-depth reliable reach at >=90% observed success, and paired uncertainty where relevant. Any learned allocation policy is a subsequent iteration.
