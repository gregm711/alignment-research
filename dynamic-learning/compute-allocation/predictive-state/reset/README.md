# Which bytes are worth carrying through a reset?

Register before generating the test cases. A device is observed once, the solver's whole session is reset, and the device returns either unchanged or with one hidden edit. Compare (a) no persistent data, (b) a fixed number of packed raw observed answer bits in public shortest-string order, (c) a fitted recurrent operator serialized into that same byte envelope, falling back to raw evidence when it cannot fit, and (d) the identical serialized operator treated as ordinary state for a fixed interpreter. The last comparison is an equivalence control. Equal bytes and equal computation allow the state interpretation to implement the same function. This experiment tests which content should persist; it cannot establish a physical distinction between stored coefficients and program data.

Use independent seeds 611903 (linear and random finite-state rules) and 711903 (modular digit streams). For each family and sizes 4/6/8, draw 16 source machines whose training table differs after the proposed edit. Test the two futures of each saved episode on identical queries. Use 8/16/24/32-byte caps including payload tags and dimension metadata. Charge old-world compilation and serialization separately; deployment includes loading, verifying, new observations, refit and sixteen long predictions. Every stored payload has exactly B bytes; read-only code and the shared prefix ordering are common. No source labels, model objects, query histories, gradients or cache addresses survive the reset.

Before trusting memory check four distinct short inputs plus twelve independently drawn long guard inputs where a model is available. If stale, reacquire evidence and fit a fresh operator. Raw evidence may also be used provisionally after its short checks, then discarded and refitted if it conflicts with new measurements. The cold solver and evidence decoder may try different prefix/suffix splits of the available raw table and stop early. Report exact all-string certification on initial and recalled rules separately, harmful stale accepts, cold-observation savings, memory use, process energy per solved recall, and the number of recalls needed to repay preparation at equal accuracy where defined. The simulated teacher's answering cost is included; communication is reported separately. Expect direct transitions to save repeated decoding on stable high-rank worlds where they fit, raw evidence to stay useful at small budgets, and the identical-payload interpreter to match transitions on every trial. Full refitting on detected changes is the baseline for subsequently testing local weight revision.

## Direct weight repair after a verified contradiction

Reset runs found a 24-byte fitted memory cheap on unchanged linear worlds; changed worlds usually required a fresh fit. Test a new architectural action: modify the recovered operator in its existing coordinate system. Register a readout-only fit and a rank-one transition repair. For one suspected changed action, use repetitions of the other action to prepare independent old states and independent output tests. If these span the old model, a one-action experiment measures one entry of the update matrix in those coordinates. A nonzero pivot and its row and column determine a rank-one update over GF(2). Verify every receipt plus twelve common guards; on failure either abstain at the acquisition cap or refit from the already paid observations. The rule-change class is an explicit prior. This does not assume that an online gradient found that prior.

Use a 32-byte persistent envelope. Begin with the same old training observations and byte writer. Supply all arms one new verified observation that contradicts the old true machine; count it and report its simulated discovery separately. Compare cold progressive refitting, refitting plus output-only revision, enumeration of one coefficient flip in the old basis (using common verification observations), and output plus rank-one revision with identical refitting fallback. Compare caps 24, 64, 128 and 300 unique current observations including the report. A solve requires a certified initial machine and a certified revised one, plus identical predictions after serializing the revised machine in 32 bytes and resetting its state again. Report conditional accuracy on arms' common eligible initial machines as well as the unconditional total and count every queried bit. Raw-only fallbacks are allowed to refit current observations; their saved raw evidence gets no presumption of validity after a known contradiction.

Use 16 fresh pairs at widths 4, 6 and 8 per linear/finite-state/modular family (seed 831947). Freeze the repair before testing a new family of opaque permutation devices in which one action swaps two destinations on its alphabet. That edit is rank one in the full one-hot representation. The learner sees only strings and one-bit outcomes. Hidden state mergers can destroy identifiability in the old compressed basis. Predict output-only revision helps modular readout changes, and rank-one revision rescues some true transition changes below the cold refit budget. Advance it as an energy improvement only if it also beats the strongest simpler arm at equal certified accuracy. Audit query caps, false accepts, withheld predictions and second-reset serialization. These are actual coefficients of an executable recurrent model; the slow neural chooser is frozen throughout.
