# Discovering recurrent coordinates from observed behavior

## Prospective test

Fit from a binary string and its one-bit outcome only. A history is represented by what the device will do after several possible continuations. Each independent pattern of future responses supplies a new coordinate. Learn the two recurrent transitions from these observations by elimination over GF(2). The fitted state, transitions and output function are specific to the new machine. No true state, rule-family identifier, transition table or dimensionality is provided. This is finite-field Hankel realization, a classical system-identification technique. The research question is its fully charged advantage over cheap explicit solvers and the scope of its transfer. [Hankel learning background](https://aclanthology.org/D14-2002/)

Start each phase with the exact same input table for all candidates, consisting of all 255 strings through length seven, including the empty string, and twelve guard examples of lengths 8–12. Test on sixteen previously unseen long strings composed of shorter blocks, balanced by output. One phase changes an internal transition or output rule and includes contrary evidence in the new table. Refit on that table; charge both fits. A solve requires all 32 predictions correct. Count the example acquisition separately from CPU joules. This protocol can test representation recovery and transfer; it starts with hundreds of observations. The test words supply sequential compositions of known symbols, rather than standalone labels for their parts.

Compare direct discovery, a conventional exact state learner merging identical rows of observable outcomes, and a hardcoded cascade. The cascade fits degree-one then degree-two parity polynomials of ordered subsequence counts, then ordinary state merging, then the same discovery fallback. A discovery-first policy tries discovery before the same alternatives. Validate proposed models against observed evidence and fresh guard examples before accepting them; abstentions and false-shortcut accepts count as failed episodes. All arms get the same evidence. Charge all attempted fits, rejected candidates, verification, revision, and production of predictions. No offline training or external calls during evaluation. Sweep the allowed latent rank 2, 4, 8, 15 at fixed input. Allow the conventional learner all 15 observable rows at every rank. Include a scrambled continuation control at maximum rank, breaking the correspondence between the same continuation before and after an action while preserving its marginal frequency.

First test 24 seed-paired worlds per hidden dimension 2, 4, 6 and 8, consisting of randomly drawn binary linear transition systems with one changed matrix entry, and 24 control worlds visibly generated by first/second-degree word statistics. Seed 814103. Reject constant worlds, indistinguishable revisions and worlds incapable of furnishing the fixed balanced evaluation set. Count rejections. Freeze all fitting and evaluation choices before reading the independently specified seven Tomita regular languages. Score all 42 directed grammar revisions at the same budgets and disclose repeated grammars and small effective sample size. Predict that discovery will solve at least 90% at dimension six at adequate rank while exact observed-row merging fails on most such cases. Advance an efficiency claim only for equally accurate policies, including the strongest simpler standalone fit. On transfer require a same-accuracy energy advantage over both hardcoded cascade and ordinary state merging where eligible. Failure on either limits the architecture claim. Use XNU process CPU energy, three batched timings, no GPU. Report maximum reliably solved difficulty at each budget and how much stronger the evidence is than a small base-rate predictor.

Before implementing scorers, add an all-strings audit. Represent the fitted and ground-truth machines independently as linear transitions over binary vectors (one-hot states for ordinary finite automata). Close the reachable span of paired states under both actions. A mismatch yields an explicit counterexample string; matching output on a spanning set proves equivalence for every finite string under the supplied machine semantics. The grader alone sees the ground-truth realization. Record finite-test success and certified success separately. Charge auditor energy separately from deployable prediction. For interpretation, these constructed worlds support a mathematical guarantee within finite-state semantics.

External reference implementations differ on acceptance of the empty string for the second grammar. Use the pinned LC-John/RNN2DFA transition definitions, which accept it for (10)*. Before any external scoring, allow a grader-only sampling repair if random concatenations fail to yield eight distinct accepted words in 6,000 draws. Enumerate periodic words of lengths 14–40 with motifs of lengths 1–5 to complete a balanced panel. Report repairs. All-string certification is independent of this sampling.

## Fixed-evidence baseline repair and extreme compositional depth

The fifteen-prefix equality learner recovered 30/42 Tomita revisions. Give it an adaptive layout before attributing the gap to learned coordinates. Using the same 255 short outcomes, try (maximum prefix length, maximum suffix length) = (3,3), (4,2), (5,1), (6,0), (2,4), (1,5), (0,6). Stop at the first candidate passing the complete observed table and guards. Charge failed layouts. Compare standalone discovery, the expanded equality learner and a cascade including this stronger learner on identical episodes. Pair timings in shuffled order with seven repeated batches. Keep the original preregistered run.

A distinct extrapolation test will present two new reversible transition rules as initial and changed devices, still learned from the original short observations. Generate 12 fresh worlds each at widths four and eight using independent invertible binary matrices; revision adds one coordinate to another in the output of one action. For each query, four compositional blocks are obtained by repeatedly concatenating pairs of the four previous blocks, doubling their length at every level. Each level's four ordered pairs are sampled without replacement (seed 919221). At levels 6, 24 and 96, produce sixteen binary answers in each phase on short random prefixes, long blocks and short suffixes. The largest block has 2^96 symbols. Audit the fitted model for all strings, plus compare predictions to an independently evaluated compressed reference. Explicitly check shortcut controls that ignore the long block or stop after six levels. Report constant-case rates. The objective is exact behavior on a *single* supplied compressed instance; this input format contains explicit reusable subexpressions.

Compare memoized execution on reached (block, state) pairs, composing the discovered linear transitions on their basis, and dense composition of the same transitions over all states. Use the same fitted model and DAG for all three. Never send hidden transitions to a solver. Count actual work spent if the allowance expires, and include readout, fitting, verification and failed attempts in the meter. Sweep 512, 4096 and 32768 units per phase, charging one unit for each application to a state during block execution or compilation (memo calls for uncached nodes, compiled basis or state entries, plus use at query time). Charge short context explicitly. Count cache entries separately. All operators fit in bounded workspaces at the specified widths and depths; no distributed or parallel speedup is assumed. Predict that basis composition reaches level 96 on eight-dimensional reversible worlds within 4096 units and outperforms memoized execution at that cap. Report unconditional solves and ceilings from short-evidence identifiability. Any energy advantage requires equal solves. If a finite model of the wrong world passes the short evidence, its deep answers remain uncertified.
