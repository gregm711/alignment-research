# Can a learner remember what to check?

## Pilot registered before scoring

Use both ABB systems from the public Adaptive Test Case Selection data at revision 85bae8b6dd58ef7d49c4c15690ba628a5187d4f7. Replay cycles in numeric order. Only the list of tests run upstream is visible at the start of each cycle. Read Name and Verdict. Withhold LastResults, current outcomes and current duration. All historical logged outcomes become available after each completed cycle; this models early feedback during an eventual full run. Within a cycle a policy sees only answers to its own checks. Collapse duplicate records with the same test name to a single test (any failed execution counts as failure); report duplicate counts. Use the first third of cycles solely to acquire history. Use a rolling archive of the last 32 completed cycles. These two systems are pilot data, henceforth unavailable for final confirmation.

Spend up to eight checks, reporting budgets 1, 3 and 8. Fixed baselines rank available tests by smoothed per-test failure frequency and by the most recent known outcome then smoothed frequency. Also report exact uniform sampling without replacement and the hindsight upper bound. The adaptive comparison retrieves related cycles, downweighting older outcomes inconsistent with checked results by a factor of 0.1 per mismatch (ignore missing values). Rank the next test by weighted failure frequency with one pseudo-pass and one pseudo-failure. The exploratory policy spends the first check asking which test best separates historical failure patterns, then uses the same adaptive reader for the remaining checks. For this cheap first implementation, rank candidate probes by the summed expected reduction in variance of other test outcomes from observing their answer, using historical pairwise covariance squared divided by the probe variance. Shrink by pair coverage; require four joint observations. Both policies see the same archive. Break ties by historical frequency then lexical test name. Compare also to a random-first check followed by the same adaptive reader. The diagnostic probe may be an expensive detour.

Primary outcome is fraction of failure-containing cycles with at least one failure found by check three. Secondary outcome is fraction of all logged failures found at eight checks. Fixed count measures executions; the dataset provides approximated runtimes and this pilot does not establish wall-clock, energy or production savings. Publish per-cycle counts and all methods. Predict adaptive retrieval will improve first-failure detection by at least five points over the better fixed rule in both systems. Require a positive paired lower bound on both (10-cycle moving block bootstrap). The diagnostic probe must beat greedy adaptive retrieval on both systems before pursuing it for this objective. Report build counts, failure prevalence, attainable ceiling and dependence on contiguous runs. A failed gate should redirect effort. A scientific result suitable for a large architectural claim would need untouched independent projects, measured cost, mechanism ablations, and a fixed decision rule.

## Prediction-market pilot registered before scoring

On the same cycles compare four probability forecasters: 32-cycle smoothed frequency, latest known verdict mapped to 0.9 or 0.1 (0.5 if unseen), smoothed frequency over four cycles, and the conditional episodic reader above. All see the same build and verified evidence at the time of prediction. Use their arithmetic mean as the fixed equal-share baseline. A second policy maintains four shares *per test identity*, updating only that identity at the end of a logged cycle. Each expert invests its share according to its probability forecast. Following settlement, multiply its share by the probability it assigned the observed result, normalize, then return 5% of wealth to uniform to permit recovery. Settlement uses only pre-probe forecasts so adaptation is identical under any action policy. This is a local specialist market with fixed participants. Compare to multiplicative expert weighting, which is mathematically identical under log loss; it is a sanity check and a limit on novelty. Report average per-build log loss in bits on all scheduled tests before observing any result, and the same downstream adaptive detection endpoints as above. For a practical win require at least 0.01 bits per test saved over equal shares, with a positive lower paired block bound, in both systems, plus a nonnegative three-check detection point estimate in both. Payouts in this pilot use full eventually released test outcomes. They do not establish scalable upstream credit assignment or benefits to spawning modules.

## Pilot outcomes

Most failing builds were easy to flag. Prioritizing previously failed names and breaking ties by historical frequency found a failure within three checks on 187/197 failing Paint Control cycles and 168/183 failing IOF/ROL cycles. The adaptive historical reader reached 191 and 169. Its paired gains were 2.03 points (95% moving-block interval −0.48 to 4.93) and 0.55 (−2.15 to 2.86). The five-point target failed on both projects.

| Three checks per failing build | Paint Control | IOF/ROL |
|---|---:|---:|
| Exact expected rate under random ordering | 33.4% | 74.4% |
| Prior failure history with latest verdict prioritized | 94.9% | 91.8% |
| Retrieve past cycles after each answer | 97.0% | 92.3% |
| Spend the first check on diagnostic information | 95.9% | 91.3% |
| Equal-weight forecasters | 95.9% | 92.3% |
| Local market of forecasters | 96.4% | 91.8% |

The diagnostic policy aims to reduce uncertainty across test outcomes. Its three-check detection rate was lower than greedy retrieval on both projects. There was little opportunity for an information-seeking first step on IOF/ROL: the diagnostic scores were all zero on 153 of 214 cycles. This arm recomputes the probe from a rolling archive, which provides a baseline for any architecture that learns and retains reusable questions. It does not demonstrate such an architecture.

The market saved 0.030 bits per test forecast on Paint Control (0.002 to 0.058) and 0.015 on IOF/ROL (−0.005 to 0.035) over equal weights. Its three-check detection advantage failed to replicate. After **one** check it found failures on 183 versus 176 Paint Control cycles and 158 versus 146 IOF/ROL cycles relative to equal weighting. This was an exploratory observation. Before the first check the conditional forecaster duplicates the 32-cycle frequency predictor, so these forecasts have three distinct signals. Ordinary multiplicative expert weighting reproduced the market's settlements. We have no evidence for a separate scaling benefit from market exchange.

**Measurement limits.** Cycle order and the currently scheduled test names are supplied. All prior cycle results are eventually revealed. This avoids leakage from the supplied historical-results column. The USD or energy cost of running a test is unknown. Each charged probe represents one distinct test name. It aggregates repeated executions by asking whether any failed. There were 3,334 duplicate records on Paint Control and 4,596 on IOF/ROL across the full panels. In the scored windows, 447 and 1,432 test-name groups contained both a pass and a fail. A post-run sensitivity using only the first recorded verdict per name reduced the retrieval gains over latest to +1.57 and −0.55 points. The diagnostic policy still lost to direct retrieval in both. Different identity, timing and censoring assumptions could change the findings.
