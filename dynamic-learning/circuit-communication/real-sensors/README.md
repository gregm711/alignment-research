# Hidden-dependence pooling on measured gas-sensor streams

## Protocol recorded before scoring

Use both recordings in UCI's Gas Sensor Array under Dynamic Gas Mixtures. In each, 16 gas sensors sample a changing mixture containing ethylene and one interferent (CO or methane). The binary target is the commanded ethylene set point above zero. The gas controller supplies the target independently of the array. A set point describes the command; the concentration at a sensor can lag. The published sensor model IDs and interferent concentrations are withheld from every receiver. Sensors can agree through common exposure, sensitivity or lag; this dataset has no annotated copying graph. [UCI data and documentation](https://archive.ics.uci.edu/dataset/322/gas+sensor+array+under+dynamic+gas+mixtures)

Take the first recorded sample in every five-second elapsed-time bin with no interpolation. Keep each complete run in its original order. Use the earliest 25% of each run to learn one signed threshold per sensor by maximizing balanced accuracy over both directions and 39 training quantiles (2.5% through 97.5%). The deployment segment is the later 75%. The last eight training readings initialize the hidden-dependence estimator. Fit separate encoders per mixture. No held-out target, current other gas concentration, future sensor reading or actual change time enters a policy.

Deploy majority, one fixed training-best sensor, a competence-weighted vote (positive log odds of each channel's smoothed training balanced accuracy), and the original eight-reading Hamming estimator. Two histories are neighbors when their eight-bit Hamming distance is at most one, and each vote is weighted by inverse count of neighbors including itself. All receivers break exact ties in favor of absence. Recompute the Hamming map every 1, 2, 4, 8, 16, 32, 64, 128 or 256 events, freeze it at initialization, or use the inherited reactive gate. The gate treats a neighborhood of at least eight as suspicious, flags absolute vote agreement below 0.75 or an empty suspect set, and triggers after two flags in four events with a six-event cooldown. A revision first affects the next decision. There are no newly purchased labels. Score accuracy and balanced accuracy, and report the first 30 seconds after a real binary set-point change. Describe bin spacing and target run lengths to distinguish intermittent target jumps from unobserved sensor dependency changes.

The primary transfer claim requires a higher held-out balanced accuracy than majority in both recordings and no fixed clock with equal or higher balanced accuracy at equal or lower measured energy in either. Report the highest-scoring fixed clock as a descriptive held-out envelope, alongside ordinary accuracy and paired intervals from 2,000 paired temporal-block bootstrap draws of consecutive five-minute blocks. Two streams from one array constrain generalization. Use exactly the same compiled scalar streaming C kernel, inclusive of vote encoding, for all modes. Charge sixteen logical report bits per event for all ensemble arms and one for the selected single sensor, eight historical report vectors at initialization for dynamic arms, zero paid checks. Report process CPU energy and elapsed time for each arm with repeated fresh-state replay on one CPU. Exclude fixture acquisition, calibration and scoring from this inference measurement. Strict dominance on timing is descriptive at the resolution of these measurements.
