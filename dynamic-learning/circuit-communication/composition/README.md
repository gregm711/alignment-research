# Can a circuit recruit another circuit to execute a new composition?

## Protocol fixed before scoring

Each worker owns a fresh random permutation of 16 symbols. A query starts with a public four-bit value at a named entry worker. The worker computes the value that the next worker must transform. Five layers each contain 8, 32 or 128 workers. Two public outgoing edges lead to different workers in the next layer. The next destination depends on an instruction and the parity of the current output. A stop instruction ends the computation. Every query supplies five noisy instruction vectors, including distractors after stopping. The controller sees the current returned value and instruction. A worker can reveal one lookup per contact. Worlds remain independent across training and evaluation.

Fit one small linear action classifier with interactions between instruction features and output parity, using supervised local decisions on one- and two-step examples with width eight. Freeze it. Evaluate new worlds with one-, three- and five-stage problems at each width. Exact answers are generated by the clean latent instructions and private tables. Three- and five-stage compositions are absent from training. A conventional router knows the instruction distribution and decodes by nearest prototype. It can use the same point-to-point interface or access centrally resident tables. An extra comparator keeps only the first result. A severed-link comparator replays the learned router's *exact worker addresses and number of contacts*, replacing only the input to the last worker with an independently drawn symbol. Keep single-contact queries untouched. Thus sending a scalar vote from several workers cannot satisfy the task. The intermediate four-bit value is an argument to another unknown function.

Predict at least 95% exact accuracy on the unseen five-stage computations and a paired improvement of at least 70 percentage points against severed-link replay at all widths. Expect the learned controller to fall within two points of the ordinary router. A result in that range establishes learned execution of new compositions under a narrow interface. The local functions, pair of edges, labels for training the router, and cell addresses are supplied. This study does not test discovery of new functions or a physical parallel fabric.

Per query record accuracy, distinct active workers, logical requests and replies, bits including one destination header per message, and externally verified checks (zero during inference). In the star protocol a request carries a worker address and four argument bits; the sequential reply carries a coordinator address and four output bits. Layer-specific IDs and the coordinator share one address space. The workload has one outstanding request per query, so sequence numbers and return addresses are implicit. The input query is already at the coordinator. The centralized control accesses an identical in-process table, with no per-query communication. Count its initial private-table upload separately. Use 12 independently seeded held-out worlds per width, 240 balanced-by-design queries per depth per world; pair the arms and bootstrap world means. Repeated process CPU energy and elapsed-time readings cover inference on identical pregenerated problems, including action selection, memory access and final answer, with no physical networking. Measured hardware quantities cannot be inferred from logical wire bits. Report raw world-level results and meter readings separately. No search on the held-out worlds.

## Results

The learned router met the registered five-step criteria at all three widths. It learned to execute new multistep compositions from demonstrations of local decisions. The ordinary nearest-prototype router matched its accuracy and consumed less process CPU energy in each measured workload.

Each cell covers 2,880 queries across 12 fresh worlds. At the largest width and depth, learned minus severed was +92.85 percentage points (paired world bootstrap 95% interval +91.88 to +93.78). Learned minus ordinary was +0.035 points (−0.069 to +0.139). The replay retains the learned worker addresses and touches the same private tables. Replacing the last argument drives accuracy close to its 1/16 chance level. Small differences in the one-stage rows arise when a router misreads the stop instruction and visits two or more workers. Always using just the first worker solves every one-stage query, and scores 6.49% at the largest width and depth.

### Energy, time and traffic

The learning phase fit 18 coefficients using 11,520 labeled local actions. It took 5.4 ms elapsed and 0.018 J of process CPU energy in this run. One set of weights served all widths and depths. At 128 workers per layer and depth five, the learned router consumed a median **1.72 µJ of process CPU energy and 0.496 µs elapsed per query**. The conventional decoder used **1.25 µJ and 0.359 µs**. The numbers are batch throughput on one Apple Silicon process, at batch size 240. They include routing, arithmetic and local memory reads, with all private tables already resident. Each timing block ran the final world's fixed batch repeatedly. Three readings per condition lasted at least 100 ms each. Similar accuracy here favors the conventional readout on cost. Raw elapsed, CPU-time and energy deltas are included for all sizes. Device/network energy and individual query latency require other measurements.

All inference arms used zero external verification checks. Distributed methods charge two packets per lookup. A four-bit argument or response plus a ten-bit destination field costs 14 bits per packet at width 128. With 640 workers, the table payload for the central solver is 640 × 16 × 4 = 40,960 bits. A one-time upload in a fixed public order to a named coordinator, with a ten-bit destination header per table, costs 47,360 bits. Under this ideal serial framing, roughly 340 five-stage queries at the measured 139.68 bits per query cover the initial upload. Repeated use of a stable central copy can therefore beat per-query routing. These wire costs omit link-layer framing, synchronization, fault tolerance and replication. All arms ran on one physical process. The conventional and central rows reuse the very same exact access and readout, so both have the same measured in-process performance.

The experiment gives workers their functions, a known topology, a fixed four-bit interface, supervised routing actions and clean synthetic semantics. Increasing width increases available modules and address cost while live depth stays fixed. The task verifies recruitment and information flow, without establishing that additional workers improve attainable intelligence or that this mechanism solves historical phone revisions.
