# Model candidates for the bounded-writer experiment

Catalog checked November 25, 2026. I would spend the first local inference run on **LFM2.5-350M**, then compare it with **LFM2.5-1.2B-Instruct** on exactly the same development episodes. Both are post-trained, text-only Transformers checkpoints with accessible weights. The smaller model's card reports IFEval 76.96 versus 59.94 for direct-answer Qwen3.5-0.8B in that evaluation. The 1.2B card reports IFEval 86.23 versus 73.68 for direct-answer Qwen3-1.7B in its evaluation. Liquid AI ran those benchmarks. A same-precision, same-prompt full-history fork test and a viable training path decide the final choice. A model's parameter count and the writer's persistent bytes are separate experimental resources.

**Direct-answer escalation.** Artificial Analysis lists Qwen3 4B 2507 Instruct with a null v5 headline score. Its July 2025 instruction checkpoint is a text-only, non-thinking decoder.
